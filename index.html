Project 01

Lead Voice Agent Ops

Autonomous Inbound GTM & Voice Qualification Pipeline

The problem

Sales and GTM teams lose hours manually researching inbound signups, scoring fit, and scheduling discovery calls—while fully unconstrained AI dialers risk mishandling high-stakes enterprise leads.

Architecture & guardrails

Event-driven inbound sales automation. An LLM enriches and scores each lead against ICP criteria. High-stakes calls route through a human-in-the-loop approval gate—Slack or a web dashboard with admin write-unlock—before an ElevenLabs voice agent dials, handles product Q&A, qualifies intent, and books the demo.

MLOps & agentic governance

Local-first MLOps sits on that same path — dashboard tab and APIs, with the Cloud Run demo left view-only. A versioned prompt registry, file-store MLflow traces, and golden evals make qualification and post-call extract auditable. Judges are heuristics, not a second model. The point is evaluation, auditability, and blast-radius control for an agentic GTM workflow.

  • Prompt registry

    Versioned YAML for lead_scoring and demo_extract. Active version plus content hashes. Switch with ACTIVE_PROMPT_VERSION.

  • MLflow tracing

    File-store spans for qualification, scoring, demo extract, and eval runs. The in-app trace log shows latency, tokens, cost, and prompt hash.

  • Golden lead evals

    Fixed quiz leads. The gate matches the live rule: Fortune 500 or ICP ≥ 90 is Selected. Default 3 passes. Mean score and range, gate votes, and heuristic judges for groundedness, gate accuracy, and tone. Run from the UI or CLI. Each run keeps a snapshot.

  • Golden demo evals

    Simulated post-call transcript and summary fixtures for demo_extract. Heuristic judges check booked versus not booked, and date tokens. Same multi-pass pattern and tabbed UI as the lead evals.

  • HITL feedback

    Call, Claim, and Reject are logged as approve-handover-to-AI, call-by-human, and lead-call-rejected, from the dashboard and from Slack.

  • Guardrails

    Select and dial are separate. A Selected lead with no phone can still go to Slack for review. Dial stays blocked.

Code: prompts/, evals/, backend/app/evals/.

02 — Huawei Stockholm, 2017–Present

Industrial AI & Real-Time Optimization R&D

Four technical pillars across multi-generation 5G/6G RAN products. Each one is the operational bottleneck, then the mathematical or learning method used to clear it.

01

Multi-Node Coordination & Teacher–Student Policy Distillation

Challenge

Coordinating decisions across distributed nodes in real time without blowing sub-millisecond hardware compute budgets.

Solution

Designed permutation-equivariant Graph Neural Networks (GNNs) for distributed multi-cell coordination (+10–15% system throughput) and built teacher–student knowledge distillation pipelines to compress heavy teacher policies into lightweight student networks for real-time execution.

02

Spatio-Temporal Sequence Prediction & Low-SNR Denoising

Challenge

Recovering accurate system state under severe noise (down to −5 dB SNR) and compensating for state aging in fast-moving environments.

Solution

Built deep learning pipelines combining spatial representation learning (CNNs, auto-encoders, channel charting) with Transformer-based temporal sequence prediction to denoise measurements and forecast trajectories ahead of time.

03

Sim-to-Real Domain Adaptation & Neural Codebook Exploration (Neural-MQ)

Challenge

Bridging the gap between synthetic simulation training data and site-specific real-world environments, and avoiding exponential codebook search complexity.

Solution

Developed domain-adaptation / fine-tuning pipelines for site-specific calibration, and co-developed gradient-based updates with temperature annealing over neural decoders (Neural-MQ), reducing search complexity from exponential to linear while outperforming 7.2× industrial baselines.

04

Constrained Cross-Layer Optimization & Low-Bit Quantized Inference

Challenge

Making joint resource-allocation decisions under strict power, hardware, and fairness guardrails.

Solution

Formulated and solved constrained convex/non-convex optimization problems for joint scheduling, MCS selection, and precoding (+10–40% throughput/worst-user rate gains), alongside low-bit (1–2 bit) iterative quantization denoising (cutting multiplication complexity by up to 40%).
